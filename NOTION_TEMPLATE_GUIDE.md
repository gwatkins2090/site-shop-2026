# Artist Portfolio - Notion Template Setup Guide

This guide will help you create an interactive Notion template that your artists can easily fill out.

## Benefits of Using Notion:
- ✅ Visual, user-friendly interface
- ✅ Progress tracking with checkboxes
- ✅ Image upload directly in the document
- ✅ Artists can save and return anytime
- ✅ Easy to duplicate for multiple clients
- ✅ Can add comments/questions inline
- ✅ Mobile-friendly

---

## How to Set Up in Notion:

1. Create a new Notion page
2. Copy and paste the structure below section by section
3. Duplicate the page for each new artist client
4. Share the page with your artist (give them "Can edit" permissions)

---

## NOTION PAGE STRUCTURE

Below is the content to paste into your Notion page. Use Notion's formatting features:
- Use `/h1` for main headers (## in markdown)
- Use `/h2` for subheaders
- Use `/toggle` for collapsible sections
- Use `/checkbox` for checklist items
- Use `/quote` for example text
- Use `/image` for image upload areas
